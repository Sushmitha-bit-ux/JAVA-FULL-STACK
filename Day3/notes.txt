Lists in Html:
-------------------
List is used to display items in organized way.

Types:
    1.ordered list:
        <ol> </ol>  represent the ordered list using that
        <li> </li>  contains list of items
        Order list attributes:
        -----------------------
            1.start  ->numbers
            2.type   ->1,a,A,i,i
            3.reserved

    2.unordered list:
        <ul> </ul>  represent the unordered list using that
        <li> </li>  contains list of items
        attributes:
            type --  none,disc,circle,square

    3.Description/definition list:
        <dl></dl>  represents the description list
        <dt></dt>  repredents the description term
        <dd></dd>  represents the description data

    4.Nested list:
        list inside a list
